# Развёртывание

## Vercel

Проект использует Next.js 16 с режимом `output: "standalone"`. Production-сборка выполняется командой `bun run build`.

Для генерации Prisma Client во время установки зависимостей в окружении сборки задаётся `DATABASE_URL`. В GitHub Actions используется временная SQLite-база только для генерации клиента и сборки.

## База данных

Сейчас пользовательские данные приложения (профиль, закладки, прогресс молитв) хранятся локально в браузере. Функция вопросов священнику отключена флагом приложения.

SQLite-файл в файловой системе Vercel не является постоянным хранилищем для serverless-функций. Поэтому включать запись вопросов/ответов в Prisma без подключения внешней постоянной базы данных нельзя. Перед включением этой функции нужно подключить поддерживаемую постоянную БД (например, PostgreSQL) и настроить переменные окружения Vercel.

## Проверка перед production

1. Убедиться, что production build завершился успешно.
2. Проверить переменные окружения Vercel.
3. Проверить preview URL и основной домен.
4. Открыть приложение в мобильном браузере и внутри WebView Одноклассников.
5. Проверить авторизацию платформы, геолокацию по согласию, карту, молитвы, календарь, закладки и локальное сохранение.
