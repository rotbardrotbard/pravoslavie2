# Источники церковного содержания

Основной справочный источник для церковных дат и молитвенных текстов приложения — **«Азбука веры»**.

## Церковный календарь

- Для выбранной даты приложение формирует прямую ссылку на ежедневную страницу: `https://azbyka.ru/days/YYYY-MM-DD`.
- Локальный месяцеслов в `menology/` нужен для работы без сети и быстрого отображения памятей.
- Локальный список — сокращённая подборка, а не замена полной ежедневной странице. При расхождении дат и перечня памятей приоритет у ежедневной страницы «Азбуки веры».
- Пасхальные даты рассчитываются по православной пасхалии; постные периоды и переходящие праздники рассчитываются отдельно от нумерации седмиц.

## Молитвослов

Основные страницы для сверки:

- Утренние молитвы: https://azbyka.ru/molitvoslov/molitvy-utrennie-bez-tolkovanij.html
- Вечерние молитвы: https://azbyka.ru/molitvoslov/molitvy-na-son-gryadushhim-bez-tolkovanij.html
- Псалом 90: https://azbyka.ru/molitvoslov/psalom-90.html
- Молитва Ангелу хранителю: https://azbyka.ru/molitvoslov/molitva-angelu-xranitelyu.html
- Молитва последних Оптинских старцев: https://azbyka.ru/molitvoslov/molitva-poslednix-optinskix-starcev-na-nachalo-dnya.html

Домашние правила приложения намеренно сокращены и не выдаются за полный богослужебный чин. Их состав и меру молитвенного правила пользователю следует согласовать со священником.

## Проверки

Регрессионные проверки календаря находятся в `scripts/test_calendar.ts` и запускаются командой `bun run test:calendar`. Они проверяют даты Пасхи, постные периоды, сплошные седмицы, родительские субботы, гласы, переходящие праздники и ссылки на источник.
